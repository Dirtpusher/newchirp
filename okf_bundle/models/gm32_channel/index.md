# gm32_channel

## Functions

- [applyGm32Rules](applyGm32Rules.md) — Applies the GM-32 transmit limits to the current frequency.
- [gm32ChannelIssues](gm32ChannelIssues.md) — Why this GM-32 row is not legal. Empty for every other radio.
- [gm32ChannelMenuLabel](gm32ChannelMenuLabel.md) — Menu line for one GMRS channel.
- [gm32DuplexChoices](gm32DuplexChoices.md) — Duplex menu for the current receive frequency.
- [gm32FrequencyIsUnset](gm32FrequencyIsUnset.md) — A new row has no receive frequency yet.
- [gm32MhzLabel](gm32MhzLabel.md) — Frequency text with six decimal places.
- [gm32NeedsFrequencyBox](gm32NeedsFrequencyBox.md) — True when the manual frequency box should start open.
- [gm32ReceiveChoices](gm32ReceiveChoices.md) — Receive-channel menu, including a manual frequency choice.
- [gm32ReceiveValue](gm32ReceiveValue.md) — Selected receive-channel menu value.
- [gm32RequiresNarrowLow](gm32RequiresNarrowLow.md) — Channels 8-14 transmit narrowband on the radio's Low step.
- [gmrsChannelNumber](gmrsChannelNumber.md) — GMRS channel stored in this row, from its receive frequency.
- [isBaofengGm32](isBaofengGm32.md) — This radio uses the GM-32 channel editor.
- [isGmrsRepeaterInputHz](isGmrsRepeaterInputHz.md) — The eight repeater inputs, 467.550 through 467.725 MHz.
- [useGm32ReceiveChannel](useGm32ReceiveChannel.md) — Puts one GMRS menu choice onto this row and starts it simplex.
